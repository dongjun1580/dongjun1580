# 안녕하세요! 👋

Java와 Spring Boot를 중심으로 백엔드 개발을 공부하고 있습니다.

기능 구현뿐 아니라 데이터베이스 설계, 문제 해결, 협업을 중요하게 생각합니다.

## 🛠 기술 스택

- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** PostgreSQL
- **Tools:** Git, GitHub, GitHub Actions

## 🚀 주요 프로젝트

### 1. Resuit
이력서 공유 및 피드백 플랫폼
- Java / Spring Boot 기반 팀 프로젝트
- 데이터베이스 설계 및 백엔드 개발 참여
- [GitHub 바로가기](https://github.com/likelion-backendschool-9th/Resuit_Prj)

### 2. Manhattan Cafe
카페 웹 서비스 팀 프로젝트
- 웹 서비스 기능 구현 및 협업 경험
- [GitHub 바로가기](https://github.com/likelion-backendschool-9th/7th_1team_ncafe)
